# ShareIt — сервис шеринга вещей

Backend-сервис для аренды и совместного использования вещей. Пользователи могут добавлять свои вещи, бронировать вещи других пользователей, оставлять отзывы после аренды и создавать запросы на нужные предметы.

---

## 🔹 Основные функции

- **Пользователи:** создание, обновление и получение информации о пользователях.
- **Вещи:** добавление, редактирование, просмотр и поиск доступных вещей.
- **Бронирования:** создание заявок на аренду, подтверждение или отклонение брони владельцем.
- **Отзывы:** возможность оставить комментарий после завершённой аренды.
- **Запросы на вещи:** пользователь может создать запрос, если нужной вещи ещё нет в сервисе.
- **Фильтрация бронирований:** получение бронирований по статусам и ролям пользователя.

---

## 🔹 Архитектура

Проект разделён на два модуля:

- **shareIt-gateway** — входной слой приложения. Отвечает за REST API, первичную валидацию запросов и передачу данных на основной сервер.
- **shareIt-server** — основной backend-сервис. Содержит бизнес-логику, работу с базой данных и обработку бронирований, вещей, пользователей и запросов.

Взаимодействие модулей происходит через REST.

```text
Client
  ↓
shareIt-gateway :8080
  ↓
shareIt-server :9090
  ↓
PostgreSQL
```

## 🔹Основные сущности
- **User** — пользователь сервиса.
- **Item** — вещь, которую можно сдать в аренду.
- **Booking** — бронирование вещи.
- **Comment** — отзыв пользователя после аренды.
- **ItemRequest** — запрос на добавление нужной вещи.
---

## 🔹 Основные API
- Для проверки API в проекте используется готовая Postman-коллекция:
```java-shareit/postman/sprint.json```

- Все пользовательские запросы используют заголовок:
```X-Sharer-User-Id: {userId}```

## 🔹 Запуск проекта
### Требования
- Java 17+
- Maven
- PostgreSQL

### Сборка проекта
```bash
mvn clean install
```
### Запуск server
```bash
mvn -pl shareIt-server spring-boot:run
```

### Запуск gateway
```bash
mvn -pl shareIt-gateway spring-boot:run
```

### По умолчанию:

- Gateway: http://localhost:8080
- Server: http://localhost:9090
